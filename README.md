# Iridescent Wallpaper Lab v0.4

Первая практическая версия после Virtual Page Engine.

Что изменилось:
- визуальный offset стал заметно чувствительнее;
- чувствительность настраивается прямо в приложении (0.70×–2.60×, по умолчанию 1.65×);
- логическая страница всё так же сохраняется между приложениями, блокировкой и перезапуском процесса;
- вместо тестовой радуги появился живой iridescent-фон с cyan / violet / magenta / orange световыми полями;
- скорость свайпа кратковременно усиливает разделение цветовых полей и ощущение инерции;
- диагностическую панель можно включать и выключать в приложении;
- добавлен `test-assets/glass_alpha_test_icon.png` — тест прозрачности Theme Park.

## Что проверять

1. Установи APK поверх v0.3.
2. Открой приложение, проверь количество/текущую страницу.
3. Начни с чувствительности 1.65×. Если мало — попробуй 1.80× или 2.00×.
4. Примени живые обои и листай страницы.
5. В Theme Park назначь `glass_alpha_test_icon.png` любой одной иконке. Если фон видно сквозь прозрачную середину и он движется внутри неё при свайпе — Samsung сохраняет alpha, и можно строить полноценный glass icon pack.

Google Discover / Samsung Free слева по-прежнему не считается обычной страницей.
