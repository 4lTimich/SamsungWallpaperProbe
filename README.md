# Iridescent Wallpaper Lab v0.5

Первая версия со стеклянной сеткой под реальными иконками One UI.

## Что появилось
- отдельный редактор сетки стекла;
- 2–7 колонок, 2–9 рядов;
- отдельная раскладка для каждой домашней страницы;
- тап по ячейке → поиск и выбор установленного launcher-приложения;
- пустая ячейка → стекло не рисуется;
- можно загрузить скриншот домашнего экрана в редактор и калибровать поверх него;
- X/Y сетки, шаг колонок/рядов и размер стекла двигаются кнопками по 1 пикселю;
- регулируемая прозрачность стекла;
- фон двигается с повышенной чувствительностью, а стеклянная сетка отдельно следует странице 1:1, чтобы оставаться под иконками;
- отладка сохранена и включается отдельной кнопкой;
- виртуальная страница по-прежнему сохраняется между открытием приложений и блокировкой телефона.

## Начальные параметры
По умолчанию сетка 4x6 и геометрия подогнана примерно под предоставленный скриншот 709x1536.

## Как тестировать
1. Установить APK поверх предыдущей версии.
2. Открыть приложение → `Редактор сетки и стекла`.
3. При желании загрузить скриншот домашнего экрана.
4. Подогнать X/Y/шаг/размер.
5. Тапнуть по нужным ячейкам и выбрать приложения.
6. Нажать `Сохранить и вернуться`.
7. Вернуться на домашний экран и проверить, совпадает ли нейтральное стекло с прозрачными кастомными иконками.

Важно: Wallpaper не двигает настоящие значки One UI и не знает их координаты. Он хранит собственную сетку, которую пользователь калибрует вручную.
