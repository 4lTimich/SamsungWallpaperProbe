# Iridescent Wallpaper v0.21 — Settled Page Cache

Это первая из двух последних попыток с `boundsInScreen` перед переходом к записи реальных свайпов.

## Что принципиально изменено

- layout-кэш НИКОГДА не меняется во время свайпа;
- каждая иконка хранится как `pageIndex + localCenterX/localCenterY` в состоянии покоя;
- абсолютная позиция вычисляется непосредственно из реального bounds:
  `pageIndex + (restX - currentX) / screenWidth`;
- anchor можно передать иконке с другой уже закэшированной страницы без rebasing и без телепорта координат;
- новая страница сохраняется только после того, как реальный offset остановился рядом с целым номером страницы;
- dock хранится отдельно и не двигается со страницами;
- старая ручная сетка и редактор не удалены;
- touch не участвует в позиции вообще в этой версии;
- renderer остаётся 120-Hz, между редкими bounds samples используется только очень короткая ограниченная экстраполяция.

## Как тестировать

1. После установки один раз выключить/включить `One UI Bounds Engine` в специальных возможностях.
2. На каждой используемой странице остановиться примерно на секунду — она должна попасть в cache.
3. После этого мотать между уже посещёнными страницами.
4. В debug смотреть `pages N`, `LB/RT`, `diff`, `POLL/CHANGE`.

Если v0.21 и ещё одна bounds-версия не дадут стабильного результата, следующая ветка будет `Swipe Recorder`: приложение запишет твои MotionEvent + timestamps + реальные bounds One UI, чтобы восстановить фактическую динамику твоего устройства.
