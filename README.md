# Iridescent Wallpaper v0.6 — performance + rectangular glass grid

Что изменилось относительно v0.5:

- ускорен live wallpaper:
  - сначала пробует `lockHardwareCanvas()`;
  - iridescent-материал рендерится в уменьшенный буфер и масштабируется на экран;
  - материал обновляется ~30 fps, а позиция стекла может обновляться до ~60 fps;
  - стеклянная пластина заранее рендерится в bitmap и переиспользуется, вместо создания нескольких градиентов для каждой иконки в каждом кадре;
  - список занятых ячеек кэшируется и больше не читается из SharedPreferences для каждой иконки каждого кадра;
  - во время перехода рисуются только две реально видимые страницы, а не лишние соседние.
- glass spring после отпускания стал быстрее.
- debug сохранён и теперь показывает FPS + HW/SW + размер фонового буфера.
- новая геометрия сетки:
  - ширина ячейки отдельно;
  - высота ячейки отдельно;
  - зазор X отдельно;
  - зазор Y отдельно;
  - X/Y первой ячейки по-прежнему по 1 px.
- старые настройки v0.5 автоматически мигрируют в новую модель так, чтобы сетка сначала выглядела максимально похоже на прежнюю.
- если загружен скриншот, редактор больше не рисует поверх него вторую копию иконки приложения; остаются стекло, рамка и маленькая метка координат.

## Порядок калибровки

1. Попади первой ячейкой в первую иконку через `Сетка X/Y`.
2. Настрой `Ширина ячейки` и `Высота ячейки` под реальный размер иконки.
3. Настрой `Зазор X` — он исправляет накопление ошибки к правой колонке.
4. Настрой `Зазор Y` — он исправляет накопление ошибки к нижним рядам.
5. Назначь приложения нужным ячейкам.
6. Включи отладку на главном экране приложения и проверь `FPS` во время свайпа.
